ALWAYS: when numerically optimizing a minimax (outer player picks a config, inner adversary best-responds via nonconvex continuous optimization), rerun promising-looking outer points with substantially MORE random restarts before trusting them — low-restart runs can make suboptimal outer configs look artificially good because the inner adversary's optimizer got stuck in a local optimum (this flipped which config looked "best" between 30, 60, and 150 restarts in imo-2026-03's n=2 case; only ~150 restarts gave a trustworthy exact match to a clean fraction).

Equal/repeated piece sizes are a liability, not a strength, against a pairing-savvy adversary.
