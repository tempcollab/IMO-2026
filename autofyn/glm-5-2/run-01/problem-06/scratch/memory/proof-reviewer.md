# proof-reviewer per-role rules

ALWAYS: independently verify "proved" periodicity machinery by generating the actual greedy sequence in Python (the IMO 2026 P6 crux — the greedy coinciding with a cyclic successor on a fixed periodic set — is empirically true but the proof's "coincidence" gap is invisible without running the sequence and checking a_{n+1} == f_B(a_n)) (round 1)
ALWAYS: when multiple builders propose the SAME theorem under different filenames (here `cyclic-successor.md` vs `periodic-set-iteration.md`), pick ONE canonical, certify it, and mark the rest "merge into <canonical>" rather than certifying duplicates (round 1)
NEVER: accept a "from-n=1 is free once injectivity holds" claim without checking — the residue transition being well-defined presupposes the admissible set is periodic mod L, which is exactly the stabilization gap (injectivity bypasses collapse into the gap they hoped to skip) (round 1)
NEVER: treat "a_N ∈ B" (the seed for the cyclic-successor orbit) as automatic — a term hits past terms via SOME shared prime, but that prime may be a large free-rider outside the kernel S, so seeding is a genuine sub-gap bundled into B1 (round 1)

ALWAYS: when a builder claims B1' (window form) is "equivalent" to M_n=M'_n (no large prime in any minimal hitting set), check the converse direction yourself — M_n=M'_n ⟹ A_n=B_n ⟹ B1' holds, but the converse fails (a large-prime minimal hitting set shows A_n⊋B_n yet the extra A_n\B_n elements need not lie in the window (a_n,b_n)⊆(a_n,a_n+R]) — so M_n=M'_n is sufficient but not equivalent. Flag the overclaim; it does not break the conditional spine (round 2)
ALWAYS: independently verify the conditional spine (B1'⟹periodicity from N) by re-deriving the seed-automaticity argument by hand: B1' at step N-1 puts a_N∈B_{N-1}; σ(a_N) hits F'_{N-1} (via contained h∈M'_{N-1}) and trivially σ_N=σ(a_N); hence a_N∈B_N=B. No circularity. This is the round's main value and should be confirmed each round (round 2)
ALWAYS: for v_p/density arguments on B1', sanity-check the threshold n_0 ballpark via Σ 1/q over primes >R diverging as log log X and product growing as exp(p_k) — for R=15, ~600 primes give Σ≈1, product ~10^{1500-2000} digits, so n_0~10^{2000} is the right order (round 2)
NEVER: accept a "Lemma 6 proves B1' for n≤n_0" claim without checking the pre-stabilization regime (n<N where F'_n has not yet stabilized) is covered — the σ-periodicity lemma requires n≥N, so the induction step only handles n≥N; the finitely many steps 1<n<N are a finite-per-a_1 check, not a uniform argument. Flag the scope gap (round 2)

ALWAYS: when testing a "periodicity" / period formula claim computationally, guard against the VACUOUS-TEST trap — if the claimed period T' exceeds the number of generated sequence terms, the loop `for i in range(len(A)-T'-5)` is range(negative)=empty and returns True having checked NOTHING. Always assert len(A) > period before trusting a True, or test the period modulo claim directly on specific residue pairs (round 3 — caught the σ-periodicity T' bug this way after the first test was vacuous)
ALWAYS: scrutinize "inflation / s-substitution" lemmas where a bound is anchored by "a big prime q of b pays for the inflation (a·q ≤ b)" — silently break when b is ALREADY k-smooth (no big prime to anchor). The false step is the conflation "n≥1 (need inflation, a<k) ⟹ b has a big prime" — these are independent (a<k is about rad(small-part), b-smoothness is about big primes). Demand an explicit case split: k-smooth b ⟹ x=b trivially; only invoke the big-prime bound when b actually has one. Probe by listing k-smooth greedy terms with small rad(small-part) and checking the construction's x≤b (round 3 — found w-descent-rsmooth's Lemma 2 bug: b=18,a_1=15 gives x=24>18)
NEVER: rubber-stamp a previously-certified lemma's formula in later rounds — re-derive the period/count when a new use case stresses it. The σ-periodicity lemma's T'=lcm(T,{p≤R:p∤L}) was certified round 2 but BUGGY when a prime p≤R divides T yet not L (drops the p factor; correct is T·∏{p≤R,p∤L}). Round-3 builders imported it; only a fresh re-derivation caught it (round 3)
ALWAYS: when an approach CLAIMS solved via a crux transplant (aimo-XXXX), verify the characterization/foundation independently by enumerating the ACTUAL greedy set and the claimed equivalent set and checking coincidence for several a_1 — the whole proof collapses if the foundation is mis-stated (round 3 — w-descent's Lemma 1 characterization G=H was VERIFIED correct, 0 mismatches, 9 a_1; this is what made the approach credible enough to invest scrutiny in its Lemma 2)

ALWAYS: when a builder "patches" a gap and re-claims solved, trace the NEW load-bearing step (not the patched one) for circularity — a common shift-the-gap move relocates the strict-decrease burden from the patched lemma to a corollary of the characterization. Verify the corollary is proved from the FOUNDATION (greedy definition) alone, not from the theorem being proved. The w-descent v2 moved the strict decrease from "r'<r (Lemma 2)" to "r<a (Cor 1.2, from Lemma 1 = greedy definition)" — NON-circular because Cor 1.2 ⟸ Lemma 1 ⟸ greedy definition, with NO use of the similarity theorem. This is the correct shape; a circular version would have Cor 1.2 ⟸ similarity/periodicity (round 3)
ALWAYS: in a minimal-counterexample descent, check whether the "purely-base-case" regime (where the descent's inflation/stripping step is trivially the identity, e.g. all terms already k-smooth) still produces a contradiction WITHOUT the strict-decrease step — if the contradiction is direct (common-prime + similarity + gcd=1) in that regime, the descent is robust to the r'=r equality case (round 3 — w-descent's purely-smooth regime a_1∈{175,221,385} handled by direct contradiction, no minimality needed)
