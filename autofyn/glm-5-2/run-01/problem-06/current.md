## Full proof
(See `/home/agentuser/repo/results/imo-2026-06/approaches/w-descent-rsmooth.md` for the complete proof. Summary below.)

**Theorem.** For every `a_1 > 1`, the greedy sequence `a_{n+1} = min{m > a_n : gcd(m, a_i) > 1 ∀ i ≤ n}` satisfies `a_{n+T} = a_n + L` for all `n ≥ 1`, with `L = ∏_{p ≤ a_1, p prime} p` and `T = |{r mod L : some n ≥ a_1 with n ≡ r (mod L) lies in G}|`.

**Proof (4 parts, all verified round 3).**

*Part I — Greedy-set characterization (Lemma 1).* Let `G = {a_1, a_2, …}`, `k = a_1`. Then `n ≥ k` lies in `G` iff `n` is coprime to none of the smaller elements of `G`. (Proved from the greedy definition alone: `G ⊆ H` by the greedy rule; `H ⊆ G` by — `n ∈ H`, `g_r = a_r` the largest `G`-element below `n`, `n` coprime to none of `a_1,…,a_r` so admissible, `a_{r+1} ≤ n`, contradiction with `g_r` maximality unless `n ∈ G`.) Cor 1.1: two distinct `G`-elements share a prime. Cor 1.2: a bad `n ≥ k` has a move `a ⟶ r` with `r ∈ G`, `r < n`, `gcd(n, r) = 1`. **[Verified: 0 mismatches, 9 values of a_1.]**

*Part II — s-substitution (Lemma 2, patched).* For `b ≥ k` with a small (≤ `k`) prime, there exists `x` with `k ≤ x ≤ b`, `x` `k`-smooth, `x` similar to `b` (same small-prime set). **Case 1** (`b` `k`-smooth): `x = b`. **Case 2** (`b` has big prime `q > k`): `x = p^n · a` (`a` = product of distinct small primes of `b`, `p` a small prime, `n` minimal with `x ≥ k`); bound `x < p·k ≤ a·k < a·q ≤ b`. **[Verified: 0 failures, 9 a_1.]**

*Part III — Similarity theorem.* Two integers `≥ k` with the same small-prime set are both in `G` or both outside. Proof by minimal counterexample: choose `(a ∉ G, b ∈ G, similar)` with `max(a, b)` minimal. Cor 1.2 gives `r ∈ G, r < a, gcd(a, r) = 1` (the **move**, non-circular — from Lemma 1). Lemma 2 gives `r' ≤ r`, `k`-smooth, similar to `r`. `max(r, r') = r < a ≤ max(a, b)` — strict decrease from `r < a` (Cor 1.2), NOT from `r' < r`. Minimality ⟹ `r' ∈ G` (if `r' ∉ G`, `(r', r)` is a smaller counterexample). `r', b ∈ G` share small prime `p'` (Cor 1.1). `p' | r` (`r' ~ r`), `p' | a` (`b ~ a`). `gcd(a, r) ≥ p' > 1` — contradiction with `gcd(a, r) = 1`. In the purely-smooth regime (Case 1, `r' = r`), `r' ∈ G` trivially and the contradiction is direct (no minimality). **[Verified: 0 violations, 9 a_1; non-circular; purely-smooth regime confirmed.]**

*Part IV — Periodicity.* `P = ∏(primes ≤ k)`. By CRT, `n mod P` determines the small-prime set of `n` (every prime `p ≤ k` divides `P`, so `p | n ⟺ p | (n + P)`). By the similarity theorem, `G`-membership depends only on `n mod P`, so `G` is `P`-periodic for `n ≥ k`. Extend to `G^* = {m : m mod P ∈ R}` (`P`-periodic, `G^* ∩ [k, ∞) = G`, `a_1 = k ∈ G^*`). The orbit is the cyclic successor `f_{G^*}(a_n) = min{m ∈ G^* : m > a_n}`. By Theorem 1 (`lemmas/periodic-set-iteration.md`, certified), `a_{n+T} = a_n + P` for all `n ≥ 1` (no pre-period — single cycle), `T = |R|`. ∎

**B1' and B2 are both closed** (the similarity theorem is stronger than B1' and gives periodicity from `n = 1` directly via Theorem 1, bypassing the conditional spine; the prematurely-valid-candidate obstruction is moot since the orbit IS the cyclic successor from `n = 1`).
