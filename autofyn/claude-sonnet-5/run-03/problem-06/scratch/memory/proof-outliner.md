ALWAYS: separate the "sufficient" direction (x with the right residue automatically satisfies all gcd constraints) from the "necessity/no-escape" direction (the true greedy minimum can't be beaten by a smaller x using a lucky prime outside S) explicitly — conflating them is the single biggest hand-waving risk on eventual-periodicity-of-greedy-sequence problems (round 1, imo-2026-06).
NEVER: assume a single prime divides all sufficiently late terms in a greedy "smallest number coprime-violating" sequence problem — explorers empirically falsified this for imo-2026-06 (a_1=35 example); the real invariant is a covering-system / signature-hitting pattern over a finite prime pool, not one common divisor (round 1, imo-2026-06).
ALWAYS: check whether a "gap" is actually an artifact of an over-truncated approximation (e.g. a finite prime set chosen a priori by size, like P={primes≤L0}) before treating it as the problem's true crux — swapping to the EXACT untruncated object (e.g. the true antichain of live constraints, already available via a certified domination lemma) can collapse a sufficiency-vs-necessity gap into a single clean claim with zero residual gap, a strictly stronger revision, not a "same wall, different label" patch (round 2, imo-2026-06).

ALWAYS: look for a crux transplant that changes the PROOF SHAPE, not just the technique, when a field plateaus on one gap for 2+ rounds (e.g. "bounded difference quotient forced to vanish by unbounded divisibility," from aimo-0680) — this can close a gap that counting/pigeonhole approaches cannot, since it never needs to fully characterize the obstruction, only show it can't recur with bounded structure infinitely often (round 2, imo-2026-06).
