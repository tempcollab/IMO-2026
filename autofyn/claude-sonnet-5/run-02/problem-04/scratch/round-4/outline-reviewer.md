## corrected-genericity-bound (revise) — verdict: CHANGES REQUESTED

The revision correctly locates and fixes round 2's bug (closure generated by
halve+shift-by-θ on seed 180−θ, not halve+reflect-on-moving-target). Technique is sound
(genericity/transcendence-degree, standard for this game). Logic of §§1–3 is valid;
§6's assembly is valid conditional on §4–§5.

Issues:
- **§5 (closed-form lemma) is a sketch, not a proof.** The induction itself is simple and
  I independently spot-verified it numerically for several n (see above) — no evidence
  against it — but "shift subtracts from the current halved value, not a stale copy" is
  exactly the kind of index bug that killed a prior approach in this workspace; the
  builder must write the induction with an explicit invariant statement and base case,
  not lean on the sketch as-is.
- **§4's algebraic (non-transcendental) wild-x1 sub-case is the real remaining risk.**
  The argument given (any $K_i$-affine-in-$x_1$ quantity with nonzero $x_1$-coefficient
  can't equal a $K_i$-target) is correct as far as it goes, but it is argued for a single
  wild $x_1$ in isolation. The outline does not explicitly handle the case where the
  play introduces a *second*, later wild cut after the first — i.e. does the induction
  compose over multiple wild insertions along one play? I believe it does (each new wild
  value is automatically transcendental/algebraic over the field that already contains
  all earlier wild values, by definition of "wild relative to $K_j$"), but the outline
  never states this composition step, and the flagged self-doubt ("needs the builder to
  verify carefully that $x_1$ never recombines with itself") suggests the author isn't
  fully confident either. This is the load-bearing gap — push the builder to state it as
  an explicit induction over the sequence of wild insertions, not just the first one.
- Gap 3 (legality domains for shift/transfer) is correctly flagged by the outline itself
  as low-risk for necessity (illegal moves only shrink the reachable set, which only
  helps the ⊆ direction) — confirmed correct, not a real threat to this approach's logic,
  just needs a one-line remark in the writeup rather than active investigation.

No fatal flaw. Sound technique, well-organized, two concrete open lemmas with plausible
mechanisms (not bare hand-offs) — proceed to build.

## backward-induction-transcendence (new) — verdict: CHANGES REQUESTED, with a
redundancy warning

Technique (backward tree induction, deriving the primitive families mechanically from
raw affine coefficients rather than a hand-built list) is a legitimate, structurally
different organization from corrected-genericity-bound's forward propagation — this is
real diversity of technique per the standing rule (same target, different mechanism is
not the same as same target + same mechanism). §2's coefficient-∈{0,±1} fact is correct
and cheap; good shared lemma to certify once written up.

Issues:
- **§4 (WLOG-x1∈K_i) is explicitly "NOT yet fully rigorous"** — its own self-assessment.
  The inductive step's key claim ("no NEW transcendental introduced below node i") is
  stated informally by "chaining the inductive hypothesis across multiple tree levels,"
  which is precisely the kind of load-bearing lemma named without a nailed-down
  mechanism that CLAUDE.md's rigor rules push back on. It needs a clean formal statement
  (what exactly is the induction hypothesis at each node, stated once, not re-described
  informally each time) before it can be trusted.
- **§5 is entirely parasitic on corrected-genericity-bound's still-unproven closed-form
  lemma.** As written, this approach's own "Current best" admits no new claim is proved
  this round beyond the imported/shared machinery. That means if
  `corrected-genericity-bound` fails to close its own §5, this approach cannot conclude
  either — the two are not fully independent evidence, exactly as the outliner's own
  "Watch out for" note says. This is *not quite* the forbidden single-gap trap (each
  slug's argument is complete and self-contained modulo imports, and each targets the
  whole problem, not a fragment) but it is close enough that the builder should be told:
  the genuinely novel, valuable work here is §4 (the multi-node wild-x1 handling), NOT
  re-deriving §5. If §4 doesn't turn out to add real robustness beyond
  corrected-genericity-bound's own §4 (i.e. if composing corrected-genericity-bound's
  single-wild-x1 argument over a play sequence is actually just as easy as this
  approach's tree induction), this approach should be recognized as subsumed and retired
  next round rather than kept as a permanent parallel track.
- **The "minimality of T" step in §4's contradiction case is under-specified** (minimal
  by what measure? depth, move-count?) — flagged already by the outline itself; the
  builder must pin this down or the contradiction argument doesn't go through cleanly.

Build this round to test whether §4's multi-node handling produces something
corrected-genericity-bound's own §4 lacks; if it turns out to be a straightforward
composition of the same idea, downgrade priority next round.

## denominator-valuation-necessity (new) — verdict: CHANGES REQUESTED

Technique is genuinely different (elementary rational/2-adic denominator bookkeeping, no
field-extension machinery) — this is the strongest diversity contribution of the round
and should be protected regardless of how the two transcendence approaches fare, per the
standing "break a shared-gap plateau" guidance (three approaches all failing on the same
wild-x1 wall would be a real risk if this one weren't in the field). The
self-flagged "watch out" note (a rational start is not automatically the *hardest* case
for Mulan, so an impossibility proof from it, if completed, is actually a *stronger*
result, not a weaker special case) is correct reasoning and worth keeping verbatim in the
build.

Issues:
- **§1 (irrational θ) has a real, if narrow, residual gap** (arbitrary irrational $x_1$
  outside $\mathbb Q+\mathbb Q\theta$) — correctly identified as structurally the same
  wild-$x_1$ issue in a smaller ambient field. This should be closable quickly (it's a
  strict special case of the machinery the other two approaches need anyway), so it's
  low risk.
- **§2 (rational θ, the entire reason this approach exists) is completely open** — an
  explicitly labeled conjecture with no derivation, only "worth checking" from an
  explorer. This is honestly flagged (good — no overclaiming), but it means this
  approach currently has zero proved necessity content of its own. The mechanism
  proposed ("bisection is the only source of new factors of 2 in the denominator") is
  plausible and mirrors a real crux move (`aimo-0355`'s monic-polynomial-denominator
  argument), so it's a reasonable thing to spend a build round on, but the builder should
  be told explicitly: if the odd-part invariant turns out **false** (a real possibility,
  since shift's denominator formula $\mathrm{lcm}(k,b)$ doesn't obviously preserve
  "$b$'s odd part divides"), report that concretely rather than forcing a fix — that
  would itself be valuable (either revealing a genuine rational-start construction
  outside {180/n}, refuting the whole conjecture, or showing this route needs a sharper
  invariant).

No fatal flaw — proceed to build, but understand this round's most likely outcome is
either a genuinely new necessity result or a clean falsification of the shared
{180°/n} conjecture, both valuable.
