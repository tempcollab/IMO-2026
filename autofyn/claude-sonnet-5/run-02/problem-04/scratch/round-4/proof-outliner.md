corrected-genericity-bound: revise (of `corrected-genericity-bound`)

Target: S = {180°/n : n ∈ ℤ, n≥2} exactly (full characterization, both directions —
sufficiency imported, necessity proved here).

Technique: genericity / algebraic-independence ("junk-coefficient") invariant argument,
exactly `corrected-genericity-bound`'s §5 architecture (which is independently correct
and certified as *reusable machinery*, not itself the bug) — but with its §2/§3 closure
computation **replaced**. The bug located last round: §2/§3 derived which "clean"
(junk-free) values are reachable using a closure operator generated by (halve, reflect
relative to a doubling target $V_i=2^i\theta$), which silently omits the shift move and
gives the too-small family $\{180/((2^k+1)2^j)\}$ — refuted by the certified 180°/7°
witness. The fix (independently converged on by two round-4 explorers, with a numeric
sweep of 20,000 random sequences finding zero counterexamples): the correct closure is
generated by (halve: $a\mapsto a/2$) and (**shift-by-θ**: $a\mapsto a-\theta$) acting on
the seed $180°-\theta$ (the fixed output of the transfer move), NOT (reflect relative to
a moving target). This is a strictly simpler and provably correct object.

Skeleton:
  1. Set up Shan-Yu's adversarial start: choose $p_0,q_0>0$ algebraically independent
     transcendentals over $\mathbb Q(\theta)$, $r_0=180-p_0-q_0$ — reuse verbatim from
     `corrected-genericity-bound` §5 (this construction itself was not the bug).
  2. Represent every angle ever present as $a=A+B\theta+Cp_0+Dq_0$ ($A,B,C,D\in\mathbb Q$)
     in the basis $\{1,\theta,p_0,q_0\}$; call $(C,D)$ the junk coefficients, "clean" iff
     $(C,D)=(0,0)$.
  3. Propagation lemma (re-verify explicitly, since the shift generator was never folded
     into the old table): for every legal move whose $x_1$ is a $\mathbb Q$-affine
     combination of currently-present angles and $\theta$ — this covers bisection, shift,
     transfer, and every other "affine" cut — the new angle's junk coefficients are an
     explicit $\mathbb Q$-linear combination of the operands' junk coefficients, and in
     particular: (halve) sends $(C,D)\mapsto(C/2,D/2)$; (shift by θ, i.e. $a\mapsto a\mp\theta$)
     leaves $(C,D)$ of the shifted angle **unchanged** (θ itself is clean, $(0,0)$, so
     adding/subtracting it never touches $(C,D)$); (transfer) **erases** the spectator's and
     partner's junk by discarding them, freshly injecting the literally clean constant
     $180-\theta$ (junk $(0,0)$) regardless of what was junky before. So the ONLY move that
     ever turns a junky lineage clean is transfer (a genuine "reset"), matching what's
     already certified; nothing else creates or destroys clean status.
  4. "Wild" $x_1$ (not $\mathbb Q$-affine in present angles/θ) exclusion — reuse §5's
     argument (extend the transcendence basis to include $x_1$; any angle carrying a
     nonzero coefficient on it can never later equal a target $2^i\theta$ by linear
     independence) — **but tighten it**: the original text calls the non-transcendental
     algebraic case "a routine extension," which is a genuine gap (flagged explicitly by
     this round's fresh-framing explorer); the builder must actually write out the argument
     for $x_1$ algebraic over $K_i:=\mathbb Q(\theta,p_0,q_0,\text{angles so far})$ but not
     already IN $K_i$ (i.e. $x_1$ satisfies some nontrivial polynomial over $K_i$ but is not
     itself a $K_i$-element) — e.g. via degree-counting in a primitive element / minimal
     polynomial, showing the same "cannot cancel to hit a fixed target" conclusion holds.
  5. **The fix.** Define $C^*(\theta):=$ closure of $\{180°-\theta\}$ under (halve) and
     (shift-by-$\theta$, $a\mapsto a-\theta$, valid only while $a>\theta$). Prove, by
     induction on the number of moves (not by numeric sweep): every element of $C^*(\theta)$
     has the closed form $x=\dfrac{180-(k+1)\theta}{2^A}$ for integers $k,A\ge0$ — track, for
     a sequence with $A$ total halvings and shifts interspersed ($b_i\ge0$ shifts occurring
     between the $i$-th and $(i{+}1)$-th halving, $0\le i\le A$), that the accumulated shift
     contribution is $\theta\cdot\sum_i b_i/2^i=\theta k/2^A$ for the **integer**
     $k=\sum_i b_i2^{A-i}\ge0$ (each term integral since $i\le A$) — this is the rigorous
     write-up of the induction both round-4 explorers verified numerically but did not yet
     formalize.
  6. Setting $x=\theta$ (transfer's own target re-appearing — this is the win condition for
     $\theta$ itself) or $x=2\theta$ (needed to feed D1's bisection double-hit): both give
     $180=\theta\cdot n$ for a positive integer $n=k+1+2^A\ge2$ (take $k=0,A=0$ for $n=2$) —
     so $C^*(\theta)\ni\theta$ (or $2\theta$) **iff** $\theta=180°/n$, $n\ge2$ integer.
  7. Combine steps 2–6: the junk-free angles ever guaranteed present are exactly
     $C^*(\theta)$ (transfer injects the clean seed $180-\theta$; halve/shift act as in step
     5; nothing else affects clean status per step 3), and by step 4 no junky angle can ever
     equal $\theta$ (or $2\theta$, feeding D1) since that would be a nontrivial linear/algebraic
     relation contradicting $p_0,q_0$'s independence over $\mathbb Q(\theta)$. Hence
     $\theta\in S\Rightarrow\theta\in C^*(\theta)$ (via θ itself or via 2θ then D1)
     $\Rightarrow\theta=180°/n$.
  8. Conclude, combined with non-obtuse-invariant (θ≤90° necessary) and the imported
     sufficiency lemma: $S=\{180°/n:n\ge2\}$.

Key lemmas (claim + mechanism):
  - **Corrected closure closed form** — $C^*(\theta)=\{[180-(k+1)\theta]/2^A:k,A\ge0\}$,
    because tracking $(A,k)$ via the binary position of each shift relative to the halvings
    already applied gives an explicit integer $k$ (proved by induction, not search) — this is
    the load-bearing new lemma, currently only numerically verified (20,000 random trials,
    zero counterexamples) by this round's explorers, needing a real induction proof from the
    builder.
  - **Shift preserves junk coefficients** — because $\theta$ is clean (junk $(0,0)$), so
    $a\mp\theta$ has exactly $a$'s junk coefficients; this closes the one gap in the original
    propagation table (shift was listed as a "messy single hit" but never explicitly folded
    into the closure computation itself).
  - **Wild-$x_1$ (including algebraic, non-transcendental) exclusion** — because any nonzero
    coefficient on a field element outside $K_i$ in an identity forced to equal
    $\theta\in K_i$ contradicts a minimal-polynomial/degree argument over $K_i$ — needs to be
    written out in full (currently hand-waved as "routine" in the source approach).

Open gaps: (a) the induction proof of the $C^*(\theta)$ closed form (step 5) — currently
conjectural-but-well-evidenced, not yet formally proved; (b) the algebraic (non-transcendental)
case of wild-$x_1$ exclusion (step 4) — currently hand-waved, flagged explicitly as needing
real work; (c) re-verifying legality domains ($a>\theta$ for shift, spectator$<\theta$ for
transfer) are correctly threaded through the abstract closure computation, not just its
algebra.

Cases to cover: θ=90° (handled directly by D2, independent of $C^*$ — fold in explicitly);
θ=180°/n rational general case (main content, step 5–7); θ irrational (automatic: no integer
$n$ solves $180=\theta n$ for irrational θ, so $C^*(\theta)\not\ni\theta,2\theta$ trivially).

backward-induction-transcendence: new

Target: S = {180°/n : n≥2} exactly (same full characterization).

Technique: finite backward induction on Mulan's assumed winning strategy tree, combined
with a transcendence-degree/field-extension argument — structurally different from
`corrected-genericity-bound`'s forward closure-propagation: instead of forward-propagating
junk coefficients through named move types, this inducts backward from the tree's leaves
using only the raw affine structure of the cut formula, so it is less likely to silently
omit a generator (the exact bug that killed two prior necessity attempts).

Skeleton:
  1. Suppose θ∈S: since Mulan forces a win in finitely many steps against *every* Shan-Yu
     reply, fix an actual finite winning strategy tree $T$ (depth $N$; every leaf's triangle
     contains θ; every internal node's two children are reachable states, with Shan-Yu
     choosing one).
  2. **Coefficient-∈{0,±1} fact** (cheap, general, no case search): from the cut formula
     $A=\{q,x_1,r+p-x_1\}$, $B=\{r,p-x_1,q+x_1\}$, every "new" entry is affine in $x_1$ with
     coefficient in $\{0,+1,-1\}$. So at any leaf where θ is the entry newly produced by that
     branch's final move, back-solving "entry $=\theta$" forces $x_1$ into exactly one of
     $\{\theta,\ r+p-\theta,\ p-\theta,\ \theta-q\}$ — reproducing the same four primitive
     families as `double-hit-primitives.md`/`transfer-and-shift-moves.md`, but derived fresh
     from the raw affine structure at each leaf, not asserted from a hand-built list.
  3. Fix Shan-Yu's start $(p_0,q_0,r_0)$ with $p_0,q_0$ algebraically independent
     transcendentals over $\mathbb Q(\theta)$ (same construction as `corrected-genericity-bound`,
     reused, not reproved). Define $K_i:=\mathbb Q(\theta,p_0,q_0)(\text{angles present at
     node }i)$ for each node $i$ of $T$.
  4. **WLOG-$x_1\in K_i$ lemma (the genuinely new, hard step)**: prove by induction on tree
     depth from the leaves upward that if some node's $x_1$ is transcendental over $K_i$, the
     subtree below it can never reach a leaf with θ via a branch through that specific $x_1$'s
     contribution — because by the coefficient-∈{0,±1} fact, any later leaf-hit identity
     "$($affine tower in the $x_1$'s used along the path$)=\theta$" with a nonzero coefficient
     on this transcendental $x_1$ is a nontrivial relation over $K_i$, contradicting
     transcendence. Hence WLOG every $x_1$ actually used along a winning path already lies in
     $K_i$ at the time it is chosen (any node violating this can be pruned from $T$ without
     losing the win, since its θ-producing descendants, if any, don't depend on that $x_1$'s
     value nontrivially).
  5. With $x_1\in K_i$ established at every used node, run the SAME junk-coefficient
     bookkeeping as `corrected-genericity-bound` steps 2–3,5–6 (clean vs. junk relative to
     $p_0,q_0$; transfer is the only clean-injecting move; closure $C^*(\theta)$ of
     $\{180-\theta\}$ under halve/shift is exactly the reachable clean set) to conclude
     θ∈$C^*(\theta)$, hence θ=180°/n.
  6. Combine with non-obtuse-invariant and imported sufficiency: S={180°/n:n≥2}.

Key lemmas (claim + mechanism):
  - **Coefficient-∈{0,±1} fact** — trivial from direct inspection of the cut formula, but
    load-bearing: it lets step 2's "which $x_1$ hits θ" classification be re-derived at ANY
    node without relying on a hand-enumerated primitive list (the exact class of bug that
    broke two prior necessity attempts).
  - **WLOG-$x_1\in K_i$ lemma** — because a transcendental (over $K_i$) choice of $x_1$ can only
    contribute a coefficient that must vanish in any later identity forcing an entry to equal
    the fixed algebraic quantity θ, by the coefficient-∈{0,±1} fact applied to every node
    along the path from that choice to any leaf — this is the crux of the whole approach and
    is currently only sketched (not fully rigorous) by this round's explorer; needs a careful
    finite-induction write-up by the builder, including the case where $x_1$ is algebraic (but
    not equal to a $K_i$-element) over $K_i$, not just transcendental over it.

Open gaps: step 4 (the WLOG-$x_1\in K_i$ lemma) is the entire open content of this approach —
currently a heuristic argument, not a rigorous induction; step 5's reuse of $C^*(\theta)$'s
closed form inherits `corrected-genericity-bound`'s own open gap (the induction proof of the
closed form) unless that lemma is proved first and imported.

Cases to cover: same θ=90°/rational/irrational split as `corrected-genericity-bound`.

Watch out for: this approach's step 5 overlaps substantially with `corrected-genericity-bound`
(same clean/junk bookkeeping, same target closure $C^*(\theta)$) — the genuine novelty is
entirely in step 4's backward-induction organization of the "which $x_1$ actually matter" question,
which is a different, more robust route to the *same* fact that `corrected-genericity-bound`'s
step 4 (wild-$x_1$ exclusion) tries to establish by direct case-splitting. If `corrected-genericity-bound`'s
step 4 is proved rigorously first, this approach's unique contribution shrinks to a
cross-check; if it stalls, this approach is the fallback route to the same gap — keep both live,
but the outline-reviewer should watch for one subsuming the other rather than treat them as
fully independent evidence.

denominator-valuation-necessity: new

Target: S = {180°/n : n≥2} exactly (same full characterization), but pursued via an
elementary, valuation-theoretic route with NO algebraic-independence / transcendence
machinery — genuinely different tool from the two approaches above, following the
"denominator/prime-support forces integrality" crux move from `aimo-0355`.

Technique: rational-coefficient / 2-adic denominator bookkeeping on a concrete rational
Shan-Yu start, split cleanly into an irrational-θ sub-case (closes easily, no genericity
needed at all) and a rational-θ sub-case (the real remaining work, an elementary
number-theoretic valuation argument).

Skeleton:
  1. **Irrational θ sub-case (closes cleanly here, simpler than the transcendence-based
     approaches' treatment of this case).** Fix Shan-Yu's start as the concrete rational
     triangle $(60°,60°,60°)$. Since $60°\in\mathbb Q$ and θ is irrational, $\{1,\theta\}$ is
     $\mathbb Q$-linearly independent, so by induction on move count every angle ever present
     (under ANY legal play, not just the four primitives — the cut formula is always
     $\mathbb Q$-affine in previously-present angles and constants) is of the form
     $a=\alpha+\beta\theta$, $\alpha,\beta\in\mathbb Q$, uniquely. The win condition
     $\alpha+\beta\theta=\theta$ forces (by linear independence of $\{1,\theta\}$ over
     $\mathbb Q$, since θ irrational) **exactly** $\alpha=0,\beta=1$ — a purely rational
     bookkeeping condition, no independence-of-$p_0,q_0$ machinery required. Track $\beta$'s
     denominator: bisection sends $\beta\mapsto\beta/2$, shift sends $\beta\mapsto\beta\mp1$
     (θ has $\beta=1$ intrinsically), transfer resets to $\beta=-1$ (the $180-\theta$ seed).
     $\beta$ is always a dyadic rational; $\beta=1$ exactly reduces to the same combinatorial
     count as $C^*(\theta)$'s closed form (import from `corrected-genericity-bound` if proved,
     else re-derive directly here — it's easier in this sub-case since $\alpha,\beta$ are
     concrete rationals, not formal junk-coefficients, so a direct induction on $\beta$'s exact
     value, not an abstract field-independence argument, suffices).
  2. **Rational θ = 180·a/b sub-case (a,b coprime integers, θ≤90° ⟹ a/b≤1/2) — the real open
     content.** Here $\{1,\theta\}$ are $\mathbb Q$-dependent, so step 1's argument degenerates
     (every angle is trivially some rational multiple of 180°; "hitting θ" is not a linear
     independence question anymore). This is exactly why the transcendence-based approaches
     use an algebraically-independent start instead of a rational one for this sub-case — a
     rational start does NOT automatically defeat off-family θ candidates. Instead: represent
     every present angle as $180°\cdot(m/k)$ in lowest terms ($m,k\in\mathbb Z$, $k>0$); track
     how $(m,k)$ evolves under bisect ($k\to2k$ before reducing), shift ($m/k - a/b$, common
     denominator $\mathrm{lcm}(k,b)$), and transfer (resets to $m/k=1-a/b=(b-a)/b$). Attempt to
     prove an invariant: **the odd part of $k$ (denominator in lowest terms) of every angle
     ever producible divides the odd part of $b$** — combined with the fact bisection is the
     only source of new powers of 2 in denominators (shift/transfer only ever combine with the
     fixed denominator $b$ of θ), this would force every producible angle's denominator to be
     of the form $(\text{odd divisor of }b)\cdot2^j$, and hitting exactly θ=180a/b (denominator
     b) forces the odd-part condition to collapse to $b=$ odd-part$\cdot 2^{v_2(b)}$ trivially
     true, needing sharper bookkeeping — this is the part flagged by this round's explorer as
     "conjecture worth checking," not yet derived; the builder's main job is to either complete
     this invariant (mirroring `aimo-0355`'s "monic integer polynomial at $p/q$ has denominator
     exactly $q^k$" style argument) or find where it fails and report that back honestly.
  3. Combine sub-cases 1–2 with non-obtuse-invariant and imported sufficiency for the final
     characterization.

Key lemmas (claim + mechanism):
  - **Irrational-θ closes without genericity** — because a rational start plus θ irrational
    already gives $\{1,\theta\}$ linear independence for free, so the entire clean/junk
    machinery of the other two approaches is unnecessary here; reduces to the same $C^*(\theta)$
    combinatorics via elementary rational tracking. This is a genuine (if narrower) simplification
    worth certifying independently even if the rational-θ sub-case stalls.
  - **Denominator/odd-part invariant for rational θ** — because bisection is the only move
    that introduces new factors of 2 into a present angle's denominator (shift/transfer only
    combine with θ's own fixed denominator $b$), an argument in the style of `aimo-0355`'s
    "monic polynomial at $p/q$ has denominator exactly $q^k$" should bound which $k$ (hence
    which θ) are reachable — **not yet derived**, this is the approach's open gap and its
    entire reason for existing as a distinct line of attack.

Open gaps: the rational-θ denominator invariant (step 2) is completely open — only a
conjecture/sketch from this round's explorer, not a proof; needs the builder to either
complete it or determine concretely why it fails (which would itself be useful information,
narrowing the field). The extension from "primitive moves only" to "any legal cut" (the same
free-choice-cut gap the other two approaches face) is unaddressed here too — flag whether the
denominator invariant is even preserved by non-primitive cuts before investing further.

Cases to cover: irrational θ (closes here, simpler than elsewhere — worth writing up even in
isolation as a partial result if the rational case doesn't close this round); rational θ (open,
main content); θ=90° (handled by D2 directly, independent of both sub-cases).

Watch out for: don't let the builder assume "rational start ⟹ automatically hardest case for
Mulan" — it's the OPPOSITE of the transcendence approaches' logic (a generic/independent start
is the *most restrictive* for Mulan; a rational start could in principle be *more* permissive
due to accidental numeric coincidences that wouldn't occur for algebraically independent
$p_0,q_0$) — so a rational-start impossibility proof, if it works, is actually evidence *for*
a stronger necessity claim, but if it's hard to complete, that difficulty may be inherent
(rational coincidences are real obstacles this approach must actually rule out, not sidestep).

Notes for the outline-reviewer: all three approaches attack the identical open gap
(necessity, S⊆{180°/n}) via three different mechanisms — forward closure-propagation
(`corrected-genericity-bound`), backward tree induction with transcendence degree

is the best candidate to keep the field genuinely diverse if the first two both stall on the
same wild-$x_1$/free-choice-cut wall — per the standing "break a shared-gap plateau" rule,
if corrected-genericity-bound and backward-induction-transcendence both dead-end on that
exact wall next round, denominator-valuation-necessity (or a further reframing beyond it)
should be prioritized rather than a third variant of the same field-extension idea.
