ALWAYS: when checking an "unsigned angle equality" translated to a polynomial via cross/dot directed-angle encoding, distinguish the TWO DIFFERENT dichotomies in play: the polynomial e=cross(X,Y)dot(W,Z)-cross(W,Z)dot(X,Y)=0 splits as θ1=θ2 OR θ1=θ2+π (mod 2π), while the literal unsigned hypothesis |θ1|=|θ2| splits as θ1=θ2 OR θ1=-θ2 — these share only the θ1=θ2 branch. A proof can validly sidestep both dichotomies at once by proving θ1,θ2 are BOTH independently strictly positive (or both negative) BEFORE invoking the hypothesis — then |θ1|=|θ2| collapses directly to the exact real equality θ1=θ2 (trivial, since a positive number is its own abs value), which then trivially forces e=0 via sin(θ1-θ2)=sin(0)=0, with no need to rule out either alternate branch explicitly. This is a legitimate, different (and correct) proof strategy from "ruling out one branch of e=0" — don't reject it just because it doesn't look like a branch-selection argument (round 5, imo-2026-02: this was exactly how the finally-successful proof closed the gap that stalled rounds 2-4).
ALWAYS: when independently re-deriving a cofactor/division identity in sympy to check a builder's claim, watch for extra spurious normalization factors baked into the builder's variable names (e.g. "A1" defined as e1/T_K directly vs. a builder writing "A1/(AC^2)" for a *different*, rescaled A1) — a mismatch in your own reconstruction is often YOUR transcription bug, not the proof's error; before concluding "solved" is wrong, redo the division exactly as the file's own equations define it (re-read the defining sentence literally) rather than guessing the scaling (round 5, imo-2026-02: first independent check falsely appeared to refute a correct identity due to reviewer's own extra division by a stray factor).
