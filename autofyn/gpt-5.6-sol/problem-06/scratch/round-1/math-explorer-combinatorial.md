## imo-2026-06
- Distinct openings:
  - **Prime-support hypergraph / clutter framing (main combinatorial route).** Replace each term by its finite prime support \(E_n=\{p:p\mid a_n\}\). The hypothesis says that the \(E_n\) form a pairwise-intersecting family, and the next integer is the first integer whose support is a transversal (hitting set) of the accumulated family. Only the inclusion-minimal members of the accumulated family impose constraints. Thus the whole problem becomes: show that the greedily generated clutter of minimal prime supports is finite. Once it is finite, admissibility is a fixed finite Boolean condition on divisibility by finitely many primes, hence periodic in the integer variable modulo their squarefree product.
  - **Static admissible-set framing.** If the final minimal-support clutter is finite, let \(S\) be all positive integers whose prime support hits every edge of that clutter. Every generated term lies in \(S\), including terms before the clutter stabilized, because every later edge intersects every earlier support. Conversely, every integer skipped by the greedy process already failed one earlier edge, so it is not in \(S\). Therefore the sequence from \(a_1\) is the increasing enumeration of the *entire* periodic set \(S\), not merely eventually the enumeration of it. This observation is important because the requested identity starts at every \(n\), with no transient allowed.
  - **Finite-state residue automaton, conditional opening.** If one can bound the set of relevant primes, the current state is the antichain of minimal supports (equivalently a monotone Boolean function) together with the current residue modulo the product of those primes. The transition is deterministic on finitely many states. Translation covariance in the integer coordinate should then convert a recurring state into \(a_{n+T}=a_n+L\). This is genuinely a discrete-process framing rather than an analytic/number-theoretic estimate.
  - **Blocker/minimal-transversal duality.** At stage \(n\), support \(E_{n+1}\) is a transversal of the current clutter. Stripping redundant prime factors gives a minimal transversal dividing \(a_{n+1}\). New clutter edges are constrained by this blocker operation. This may offer a finite-generation theorem specialized to the arithmetic order in which supports occur, avoiding direct control of all prime factors.
  - **Uniform-gap/local-window opening.** Let \(R=\operatorname{rad}(a_1)\). Every multiple of \(R\) intersects every prior support, since each prior support intersects \(E_1\). Hence \(a_{n+1}-a_n\le R\). Any argument showing that a genuinely new minimal edge needs a witness pattern incompatible with this bounded window would establish finite stabilization. This is the most obvious combinatorial pruning before deeper arithmetic.
- Candidate technique(s): prime-support encoding; intersecting hypergraphs and transversals; antichain/clutter reduction; deterministic finite-state dynamics; periodic sets of residues; bounded-gap extremal argument. The central unresolved target in this framing is **finite stabilization of the minimal-support clutter**, not periodicity after stabilization.
- Cheap-kill candidates: discard every support containing an earlier support, because it adds no gcd constraint; use \(R=\operatorname{rad}(a_1)\) to get the immediate gap bound \(a_{n+1}-a_n\le R\); work only with squarefree kernels, since exponents never affect gcd-positive incidence; exploit the finite set \(E_1\), which every edge must meet, to pigeonhole new minimal edges by an initial prime. None alone proves stabilization: pairwise-intersecting finite subsets meeting a fixed finite set can still form an infinite antichain (for example, abstractly, \(\{2,q_i\}\)), so a bare Dickson/antichain claim would be false without using greediness/arithmetic order.
