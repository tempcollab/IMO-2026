## imo-2026-06

### Distinct openings (fresh framings tried under this lens)

1. **a_1-anchor scaffold (CRT/covering-system view).** Every term (n≥2) satisfies gcd(a_n,a_1)>1, so writing P = {p_1,...,p_k} = primes(a_1) (all ≤ a_1), every term lies in the union of arithmetic progressions ⋃_{p∈P} pℤ. This is *already proved* in the existing approaches (finite-state-window's Lemma 3, density-bounded-recruitment's Step 2/Structural-Lemma setup) — it gives a coarse periodic scaffold mod rad(a_1), but **only a necessary condition**, not sufficient: E_∞ is a subset of ⋃pℤ, not equal to it, and the *extra* carving inside the scaffold (which residues inside pℤ actually qualify) is exactly what large primes could, in principle, control forever. So the a_1-anchor alone does not close the gap; it only re-derives what the field already has. Recorded here explicitly so the outliner does not waste a round re-deriving it as if it were new.

2. **Colors as a set-system / near-Helly structure.** Define, for each term a_i, its *full small-prime color* c(a_i) = primes(a_i) ∩ {primes ≤ a_1} (not just primes(a_i) ∩ P — the broader color used in density-bounded-recruitment's Structural Lemma). Computed this explicitly for a_1 = 35: 130+ distinct colors appear among the first 2000 terms, ranging in size from 2 to 5, and **every pair intersects** (checked exhaustively over all distinct colors seen — zero disjoint pairs), consistent with the Structural Lemma. I tested whether this pairwise-intersecting family has a classical "sunflower" (common-element) structure — the well-known fact that a pairwise-intersecting family of *2-element* sets is either a star (common point) or a triangle. **This does not apply here**: colors routinely have size 3–5, and there is no single prime lying in all of them (e.g. for a_1=35 some colors are {2,5}, {3,7}, {2,3,5,7,...} — no global common prime). So a naive Helly/sunflower closure fails structurally; the pairwise-intersecting family is large and "thick," not a simple star/triangle. This is a genuine dead end for a direct combinatorial-intersection argument — record it so no one re-tries plain Helly-on-color-sets.

3. **Graph/clique framing with a genuinely different closing tool: adapt the counting/density technique of crux `aimo-0447`.** aimo-0447 (see below) proves a **lower bound** on min(a,b) from a hypothesis "gcd(a+i,b+j)>1 for all i,j∈{0,...,n}" by placing a covering prime in each cell of an (n+1)×(n+1) grid and showing, via Σ_p 1/p² < 1/2 and PNT-type prime-counting bounds, that **large primes cannot cover more than half the grid**, forcing many cells onto genuinely small primes. The mechanism — *a counting bound on how many "cells" (index-pairs) a single large prime can be responsible for, versus how many cells need covering* — is structurally the right shape for Lemma A, IF we can set up an analogous grid/cell-count for our problem: e.g. cells = pairs of terms (i,j) with i<j whose intersection is exactly one prime; a single large prime q can be the *exact* intersection of at most a bounded number of such pairs among the first N terms (because a_i,a_j ≤ roughly a_1+NL are bounded, so q ≤ that bound, and the number of multiples of q below the bound is small) — this gives an upper bound on the number of pairs "explained" by q, which one could try to compare against a lower bound on how many pairs *need* to be explained without small-prime coverage. **This is a genuinely different top-level target than the three existing approaches** (they all try to show large primes are never load-bearing via local/extremal minimality arguments on a single hypothetical pair; this counting approach instead tries a global density contradiction: too many distinct large "unique-connector" primes would need too much room). Caveat: Lemma A as phrased only requires ruling out a *single* witness pair, so a pure counting argument needs an extra step — showing one witness forces infinitely many (e.g. via periodicity: once E_∞ enters a periodic regime near some point, the "same" q-witnessed pair-type would recur with density > 0, feeding the counting bound) — this extra step is NOT yet established and is the real risk of this route.

### Candidate technique(s)
- Counting/density bound on prime "coverage capacity" à la aimo-0447 (Σ 1/p², prime-counting) — a genuinely different tool from the extremal/minimality mechanisms the three live approaches are stuck on.
- CRT/covering-system language (⋃_{p∈P} pℤ) — useful as scaffolding/vocabulary but already fully derived; not a new lever by itself.
- Graph framing (vertices = terms, edges = shared prime, labelled by a witnessing prime) — useful bookkeeping, but plain Helly/sunflower facts for pairwise-intersecting families do **not** close the gap (see opening 2), so do not spend a round on Helly per se; if pursued, it must be paired with the counting mechanism above, not intersection combinatorics alone.

### Cheap-kill candidates
- Tried: "every observed color contains 2 or 3" — **FALSE** (checked a_1 ∈ {55,91,25,49,169}: every one has colors avoiding both 2 and 3), so no universal small-hub-prime shortcut exists; do not assume 2,3 are privileged.
- Tried: Helly/star-or-triangle closure on the color family — fails, colors are too large (size 3–5+), no common prime (see opening 2). Not a cheap kill.
- Possibly useful real cheap-kill (untested, flagged for outliner): a **v_q count / size bound** — if a_i,a_j share ONLY q>P_max, then since a_i,a_j ≤ roughly a_1 + (index)·(bounded gap), q itself is bounded by min(a_i,a_j) ≤ a_i, so q ranges over a *finite* set at any finite prefix; the question is whether, as the prefix grows without bound, some q > P_max is eventually forced to appear as a unique connector. A finite-prefix argument alone cannot resolve this (needs an asymptotic/global argument) — but it does mean Lemma A is not vacuous to search computationally for a counterexample (finite check), which the existing approaches already exploited (0 counterexamples on 25+ seeds, thousands of terms).

### Dead ends (do not retry)
- **Plain density/asymptotic arguments** ("only finitely many primes divide infinitely many terms") — recorded FALSE by density-bounded-recruitment: once E_∞ is periodic mod L, every prime dividing L meets E_∞ in positive density, so infinitely many primes divide infinitely many terms; density cannot isolate load-bearing primes. Confirmed correct on inspection — not re-tried.
- **Local/interval minimality** ("find a smaller compatible number in (a_{j-1},a_j)") — recorded by enum-covering-primes as provably empty (a_j is by definition the min of E_{j-1} above a_{j-1}), so Lemma A cannot be attacked by a purely local argument at the witnessing step; needs a non-local/extremal or global argument. Confirmed correct.
- **Plain Helly/sunflower on color-sets** (this round, opening 2 above) — fails because colors are size ≥3 with no common prime; a pairwise-intersecting family of size-≥3 sets need not be a star or triangle (that fact is specific to 2-element sets / graphs). New dead end, worth recording.
- **"2 or 3 are universal hub primes"** (this round) — falsified computationally for a_1 ∈ {55,91,25,49,169}; no privileged small primes exist in general.
