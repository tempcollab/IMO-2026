### Distinct openings (growth/density/finite-state lens)

1. **Universal divisor fact (proved below, cheap and load-bearing).** For every n, `a_{n+1}` was chosen requiring `gcd(a_{n+1}, a_1) > 1` (the `i=1` instance of the defining condition). Hence **every term of the sequence, from `a_2` on, is divisible by some prime factor of `a_1`.** Since `a_1` itself trivially is too, the *entire* sequence lies inside `D(a_1) = {m : gcd(m,a_1) > 1}`. This is a completely elementary but structurally central fact — every later argument about "which primes are active" should be anchored on the *finite, fixed-from-the-start* set `P_1 = primes(a_1)` (size `k = ω(a_1)`), not on an unboundedly-growing prime set.

2. **Gap bound via multiples of `a_1` (cheap-kill, confirms the prompt's hint).** For any `n`, the smallest multiple of `a_1` exceeding `a_n` is a valid candidate for `a_{n+1}`: it's divisible by every prime in `P_1`, and since (openings item 1) every `a_i`, `i ≤ n`, is divisible by *some* prime of `P_1`, this multiple shares that same prime with `a_i`, giving `gcd > 0` automatically for all `i`. Hence `a_{n+1} - a_n ≤ a_1` for all `n`. This is a genuine, fully rigorous bound (not merely eventual) — a good "opening lemma" for any approach. It's not tight in general (experimentally the true max gap is well below `a_1` once `k ≥ 2`), but it already gives: the sequence has positive lower density, gaps are uniformly bounded, and — combined with the color/state idea below — the state space needed for the pigeonhole argument is *finite independent of n*.

3. **"Color" reduction — the sharp finite-state idea.** Define, for each term `a_i`, its *color* `c(a_i) = {p ∈ P_1 : p | a_i} ⊆ P_1`, a nonempty subset of the *fixed* finite set `P_1`. There are only `2^k − 1` possible colors, **independent of n**. If `a_{n+1}` is divisible by at least one prime from each color class that has appeared among `a_1,...,a_n` (a "hitting set" using only `P_1`-primes), that's *sufficient* (not always necessary — see caveat) for eligibility, because every `a_i` with that color already has a `P_1`-prime in its factorization matching. This turns "does `x` satisfy the constraint against `a_1..a_n`" into (at least approximately, in the sufficient direction) a condition depending only on `x mod L₀` where `L₀ = ∏_{p∈P_1} p` — i.e. it's *periodic in principle*, with a state (the family `F ⊆ 2^{P_1}\{∅}` of colors seen so far) that can only grow finitely-often (bounded by `2^k − 1`) before it stabilizes. **Caveat / the actual gap**: this `P_1`-only condition is sufficient but not necessary for true eligibility, because `a_i` may share a *non-`P_1`* prime with `x` even when their `P_1`-colors don't overlap what you'd need. Experimentally (see below) other small primes (esp. 2, and sometimes 3) get pulled into the "effectively active" prime set even when absent from `a_1`. So the real state is `P_1` **plus a small number of extra primes that get recruited** — and the crux gap is proving *that recruitment also stabilizes after finitely many steps* (doesn't grow forever). This is the natural target for a finite-automaton / pigeonhole argument: define the state at step n as (the active prime set so far, gap-pattern of last window, position mod current best `L` candidate) and show it lives in a space whose size is bounded independent of n, then pigeonhole two occurrences of the same state to get recurrence, then argue forward propagation (not just eventual periodicity — see pitfall below).

4. **Direct sliding-window pigeonhole framing (crux-corpus analog).** Model eligibility as a `{0,1}`-valued (or small-alphabet) function via colors/residues, and pigeonhole over sliding windows of some fixed width `W` (related to `L` candidates) to find two positions with identical windows — this is exactly the technique used in the analogous crux `aimo-0079`/`aimo-0274` (see below) for a different but structurally similar "balanced number" periodicity problem. There the alphabet was 2 (parity of prime-factor-count of `x+a`, `x+b`); here the natural alphabet is "color of x w.r.t. `P_1` (and recruited primes)", size `2^k−1` or so, and the window width is a candidate modulus `L`. This is a genuinely different way to organize the same finite-state idea as (3): instead of tracking a single evolving state, directly pigeonhole two index positions with matching finite local patterns and use the defining greedy rule to propagate equality forward for all subsequent indices (this "forward propagation from one match" step is exactly what closes the gap in `aimo-0079`/`aimo-0274`, and is the delicate part that must be redone here since our greedy rule is far more sensitive to *all* prior terms, not just a bounded window).

5. **Density argument for the eventual arithmetic-progression shape.** Once (conjecturally) the active prime set `Q ⊇ P_1` stabilizes to a fixed finite set (experimentally: `Q = P_1 ∪ {2}`, or `P_1 ∪ {2,3}` when `3 ∉ P_1`), the *set of eligible large integers* becomes eventually periodic mod `L = ∏_{p∈Q} p` (or an appropriate LCM), because eligibility of `x` for large `x` depends only on `x mod L` (via which Q-primes divide x, intersected against the stabilized color requirements). A periodic 0/1-indicator with period `L` and density `d` forces the *n-th eligible integer* to also be eventually periodic with step `T` (the number of eligible residues per period) and shift `L` — giving exactly the claimed `a_{n+T} = a_n + L`. This is the "translate density periodicity of the index set into periodicity of the enumeration" step, standard once the periodic eligibility set is established.

### Small-case / intuition notes (all conjectural, verified only numerically)
- Ran the greedy construction (Python + sympy) for `a_1 ∈ {2,...,255}`.
- If `a_1` has a single prime factor (`a_1 = p` or `p^e`), the sequence is **immediately** the arithmetic progression of multiples of `p` (`T=1, L=p`) — no interesting dynamics; trivial case.
- If `a_1` has ≥2 distinct prime factors, nontrivial transient dynamics appear before settling into a period. Examples found:
  - `a_1=15=3·5` → period `(T,L)=(8,30)`, `L=30=2·3·5` — the extra prime `2` got recruited beyond `primes(15)={3,5}`.
  - `a_1=21=3·7`,`33=3·11` → degenerate to `T=1,L=3` almost immediately (small-prime-factor dominates fast).
  - `a_1=35=5·7` → `(T,L)=(34,210)`, `L=210=2·3·5·7` — **both** `2` and `3` got recruited even though `3 ∤ 35`.
  - `a_1=45=3²·5` → `(8,30)`.
  - `a_1=105=3·5·7` → `(58,210)`, `L=2·105`.
  - `a_1=143=11·13` → `(64,858)`, `858=2·3·11·13` — `2` and `3` both recruited.
  - `a_1=255=3·5·17` → `(128,510)`, `510=2·255=2·3·5·17` — only `2` recruited (3 already present).
- **Conjecture** (numeric evidence only, not proved): the eventual active prime set is `Q = primes(a_1) ∪ {2,3}` (with `{2,3}` only added if absent), and `L = ∏_{p∈Q} p` (the primorial-style product, not a higher prime power). This would mean **at most 2 "extra" primes beyond `primes(a_1)` ever get permanently recruited**, always `2` and (conditionally) `3` — never larger primes stay permanently active, even though larger primes transiently appear (e.g. `110=2·5·11`, `130=2·5·13` appear as *terms* for `a_1=35`, introducing `11,13` into some `a_i`'s factorization, but `11,13` do NOT end up in the eventual `L=210`). This "transient primes wash out, only tiny primes persist" phenomenon is exactly the subtle fact that needs a real proof — likely via: an odd number can only be admitted if it shares a *small* prime (3, or a prime of `a_1`) with the (growing, but density-full) set of already-included odd multiples of small primes, while even numbers are always trivially admitted via the recruited prime 2. This suggests **splitting the proof by parity as the first case split**: (a) 2 is eventually always sufficient for even candidates once enough even terms are in the sequence; (b) odd candidates need a separate, finite argument about odd primes, likely bottoming out at `{3}∪primes(a_1)`.
- This conjecture (`Q = primes(a_1) ∪ {2,3}`, `L = ∏Q`) should be explicitly tested further (more `a_1` values, and whether `3` is really special or just "smallest prime not in `primes(a_1)`") before the outliner commits an approach to it — it is currently evidence from 8 examples only, not a theorem.
