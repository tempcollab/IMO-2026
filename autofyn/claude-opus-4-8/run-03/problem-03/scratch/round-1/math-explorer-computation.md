## imo-2026-03

- Distinct openings:
  1. **Greedy-reduction opening (verified below):** since once the 2n cuts are fixed the endgame is a pure "always take the currently-largest unclaimed piece" game (no other strategic depth), the whole problem collapses to a *minimax over cut positions* of the odd-rank-sum of the final piece multiset. This is the natural top-level target for an outline: reduce → construct Liu Bang's optimal cut set → prove Xiang Yu cannot do better than the doubling response → prove no other Liu Bang cut set beats it.
  2. **Self-similar / doubling-construction opening:** the extremal Liu Bang configuration found numerically is *pieces of length 1,2,4,...,2^n* (in units of 1/(2^{n+1}-1)), i.e. cut points at (2^k-1)/(2^{n+1}-1) for k=1..n. This is a strikingly clean geometric/self-similar structure — an outline built around "why doubling sizes is optimal" (an inductive/recursive argument on n, peeling off the largest piece) is a strong, different route from a raw calculus-of-variations argument on cut positions.
  3. **Upper-bound (adversary strategy) opening:** attack from Xiang Yu's side — construct an explicit Xiang Yu strategy (as a function of Liu Bang's arbitrary n points) that provably drives the odd-rank-sum down to ≤ 2^n/(2^{n+1}-1) for ANY Liu Bang configuration, i.e. prove the upper bound c(n) ≤ 2^n/(2^{n+1}-1) directly via an adversary argument (e.g. an induction/pairing argument on pieces), independent from optimizing over Liu Bang's choice. This splits the problem into two independent halves (lower bound via construction, upper bound via adversary strategy) — good for parallel approaches.
  4. **Pigeonhole/counting opening:** with n cuts each, Xiang Yu always has enough cuts to touch at most n of Liu Bang's ≤(n+1) pieces, so at least one Liu-Bang piece survives untouched — an invariant that might drive an induction on n (peel off the top piece, recurse on the rest with n-1 vs n-1... though the counts here are asymmetric since Xiang Yu also has n cuts against the recursive remainder). Worth checking whether c(n) satisfies a clean recursion c(n) in terms of c(n-1) (candidate: 1/(3 - 2c(n-1)) or similar — see closed form below, which does satisfy a linear recursion).

- Candidate technique(s): minimax/game-value reduction to "greedy pick largest remaining" (a classical fact, reverified by brute-force minimax below); induction on n with a self-similar/doubling construction; adversary (Xiang-Yu-side) pairing/merging strategy for the upper bound; extremal/pigeonhole argument bounding how many Liu-Bang pieces Xiang Yu's n cuts can touch.

- Cheap-kill candidates:
  - **Greedy-claim justification is essentially free** (see verification below) — do not re-derive it from scratch each time; it reduces the entire endgame to "Liu Bang's payoff = sum of odd-ranked pieces (1st, 3rd, 5th, ... largest-to-smallest)".
  - **Parity/counting cheap fact:** 2n cuts (generic, all distinct) create 2n+1 pieces; Liu Bang (first mover) always gets exactly n+1 of them (the odd ranks), Xiang Yu gets n. This is an immediate structural fact worth stating up front (it explains why c(n) → 1/2 but stays > 1/2: Liu Bang always has one more piece than Xiang Yu).
  - Symmetry: reflecting the interval (x ↦ 1-x) is a symmetry of the whole game, so WLOG constructions can be built either from the left or right end (used to get equivalent-value configurations 1/7,3/7 vs 1/7,5/7 vs 2/7,6/7 — all gave the same value 4/7 numerically for n=2, consistent with the reflection symmetry of the value function, not with three distinct global optima needing separate proofs).

- Dead ends (do not retry):
  - Assuming the optimal Liu Bang configuration is *evenly spaced* points (i.e. n+1 equal pieces of length 1/(n+1)) — numerically this is suboptimal. E.g. for n=1, evenly-spaced (x=1/2) gives value 1/2 (Xiang Yu cuts at 1/2±ε creating pieces ~1/4,ε,1/4, Liu Bang gets 1/4+ε ≈ 1/4... actually verified numerically the true optimum at x=1/3 gives 2/3 > any evenly-spaced value); for n=2, (0.2,0.8),(0.25,0.75),(1/3,2/3) all gave inner-min values ≈0.50–0.503, far below the true optimum 4/7≈0.571. So "evenly spaced cuts" is a natural first guess but is NOT extremal — do not present it as the construction.
  - Symmetric-about-center two-point guesses like (1/7,3/7)-shifted-to-be-centered, e.g. (0.114,0.693) ≈ (1/7-ish, ~0.7) tested and gave only 0.558, below 4/7 — the true extremal point set (1/7,3/7) is emphatically NOT centered on the stick; it is skewed toward one end. Don't assume symmetric-about-1/2 configurations are optimal for n≥2.

- Small-case / intuition notes (all CONJECTURE, verified only numerically via grid/DE search + local-perturbation stability checks, not proven):
  - **Greedy/odd-rank reduction is solid** (not just conjecture): brute-force minimax over 2000 random small piece-multisets (sizes 1–7) confirms exactly that the first player's optimal take-turns value equals sum of pieces at ranks 1,3,5,... when sorted descending. This can be cited confidently as a lemma to prove (short exchange argument), not merely a numerical guess.
  - **n=1:** fine grid search (2000×4000 points) gives optimal Liu Bang point x=1/3 (or symmetrically 2/3), value = 2/3 exactly, matching the grid to 1e-6. Xiang Yu's best response is y=2/3 (making all three pieces equal to 1/3, so ranks are moot — any tie-break gives Liu Bang 2/3). c(1) = 2/3 (high confidence).
  - **n=2:** Liu Bang points at (1/7, 3/7) [or reflections (1/7,5/7), (2/7,6/7)] give value exactly 4/7 under a fine 4000-point grid search over Xiang Yu's response, and local perturbations of (1/7,3/7) by up to ±0.03 in each coordinate all *decrease* the achievable value (confirms local max). Broad coarse 49×49 outer grid search over all (a,b) also found this as the global best among sampled points. c(2) = 4/7 (high confidence, though global-optimality of (1/7,3/7) rests on grid search + local stability, not a proof).
  - **n=3:** Liu Bang points at (1/15, 3/15, 7/15) give value exactly 8/15 under coarse (45–60 point) 3D grid search and are locally stable under 15 random perturbations up to ±0.03 (all perturbations gave lower values). A separate broad random search (300 random Liu-Bang triples, 800 random Xiang-Yu responses each) found nothing exceeding 8/15 once the apparent "beat" was re-checked with a thorough grid (the seemingly-better candidate [0.098,0.140,0.737] evaluated to only 0.521 under a proper grid-based inner minimization — the earlier "0.536" was an artifact of too few random samples for Xiang Yu's response, a good caution for future numeric checks: **always re-verify a numeric "improvement" with a fine grid, not just more random samples**). c(3) = 8/15 (good confidence).
  - **n=4:** candidate points (1,3,7,15)/31 checked against 40,000 random Xiang-Yu responses; best found matches predicted 16/31 to machine precision. c(4) = 16/31 (good confidence, less exhaustively checked than n≤3).
  - **Conjectured closed form:** c(n) = 2^n / (2^{n+1} - 1). Equivalently, Liu Bang's optimal cuts are at positions (2^k - 1)/(2^{n+1}-1) for k = 1,...,n, producing pieces of length 1, 2, 4, ..., 2^{n-1}, 2^n (in units of 1/(2^{n+1}-1)) — a **doubling/geometric sequence of piece sizes**. As n→∞, c(n) → 1/2 from above, matching the intuition that with more cuts available to both sides the game approaches a fair 50/50 split, but Liu Bang retains a strict edge because he always ends up with exactly one more piece (n+1 vs n) than Xiang Yu.
  - Confidence: HIGH that the closed form 2^n/(2^{n+1}-1) is correct for n=1..4 (matches to machine precision across independent grid/random searches with cross-checking), MEDIUM-HIGH that it holds for general n (not proven — no argument yet for why the doubling construction is globally optimal against ALL adversary responses, nor why Liu Bang cannot do strictly better with some non-doubling configuration for larger n). The doubling/self-similar structure strongly suggests an inductive proof exists (peel off the largest piece of size 2^n/(2^{n+1}-1), argue the remaining sub-stick of relative size (2^n-1)/(2^{n+1}-1) recursively reduces to a smaller instance of essentially the same game), which should be the outliner's first target.
